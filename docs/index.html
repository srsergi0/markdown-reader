Markdown Reader

Native & fast desktop Markdown reader built with Electrobun

Markdown Reader is a lightweight, high-performance desktop application for viewing Markdown files. It features quick startup times (~50ms), small memory usage, and native file associations.

Features

  • Lightweight: Small bundle size (~14MB) compared to standard Electron apps.
  • Native feel: Uses system WebView instead of bundled Chromium.
  • File association: Double-click any .md file to open it automatically.
  • Real-time updates: Edits in external editors reflect instantly.
  • Mermaid support: Renders graphs and diagrams inside documents.

Installation Instructions

Windows

  1. Download the Windows ZIP archive.
  2. Extract the files to a directory of your choice.
  3. To set up .md file associations, open a terminal in the folder and run: 
    bun run register

macOS

  1. Download the .dmg file.
  2. Open the DMG and drag Markdown Reader to your Applications folder.

Linux

  1. Download the .tar.gz archive.
  2. Extract and execute: 
    tar -xzf MarkdownReader-Linux-x64.tar.gz
cd MarkdownReader-Linux-x64
./markdown-reader
