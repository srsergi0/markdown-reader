Installation Guide

1

Download the Windows Package

Download the latest zip package using the link above.

2

Extract Files

Extract the contents of the download zip to any preferred directory (e.g. C:\Program Files\Markdown Reader).

3

Register File Association (Optional)

To automatically open .md files with Markdown Reader, register the application dev environment by running:

bun run register
1

Download the DMG File

Download the official .dmg installer from the downloads section.

2

Install to Applications

Double-click the DMG and drag Markdown Reader into your Applications folder.

3

Open the Application

Find Markdown Reader in your Applications folder and launch it. Since it uses native CEF/system webviews, macOS may ask for initial runtime permissions.

1

Download the Linux Tarball

Get the latest .tar.gz release.

2

Extract and Run

Extract the bundle using your system's package manager or via CLI:

tar -xzf MarkdownReader-Linux-x64.tar.gz
cd MarkdownReader-Linux-x64
./markdown-reader
