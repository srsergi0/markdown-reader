Markdown Reader

v1.0.0 — Native & Ultra-Fast

Markdown Reader is a minimalist desktop viewer crafted for high speed. Built with Electrobun, it offers a tiny footprint (~14MB) and starts in under 50ms by leveraging the platform's native WebView.

[01] Native

Uses native OS views for rendering instead of heavy Chromium containers.

[02] Fast

Opens files instantly. Lightweight enough to run in the background with zero lag.

[03] Sync

Reflects file updates instantly when saved from external editors.
